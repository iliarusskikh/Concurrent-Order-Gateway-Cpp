Concurrent Order Gateway · Knowledge notes

Testing { Correctness under load }

Prove matching single-threaded. Prove plumbing with pipeline smokes that assert fills, isolation, and latency samples — not bit-identical multi-shard event logs.

01

Two layers

LayerThreadsAssertsRole
LOB golden 1 G1–G9 style book / event checks Vendored matcher still correct
Pipeline / concurrency N Fills, isolation, drops, latency counts, clean join Queues + threads + publisher work
Why split

Scheduler interleaving changes the order events hit the publisher across symbols. Golden-diffing that log across runs is flaky. Keep LOB proofs off the queues.

Run all: ctest --test-dir build. Hand-rolled expect() — no Catch2/GTest.

03

LOB golden (single-thread)

test_lob_golden.cpp calls the vendored engine directly. Event lines stay timestamp-free. Failures print FAIL: and bump a failure count.

tests/test_lob_golden.cpp
lob::MatchingEngine engine;
engine.submit({1, Side::Buy, OrderType::Limit, 100, 10});
// … assert bids / trades / cancels — no SPSC, no threads
04

Pipeline tests (what they actually assert)

TestOracle
E2E exact fill Log contains ACCEPT + TRADE maker=1 taker=2; book empty; zero drops
E2E partial Trade qty=4; residual bid qty=6
Multi parallel fills Trades on sym=0 and sym=1; both books empty
Books isolated Bid on 0 + ask on 1 → no TRADE across symbols
Unknown symbol unknown_symbol_drops == 1; empty log
Latency queue_wait / match_duration counts ≥ orders; publish samples > 0
Not asserted

Global interleaving order of sym=0 vs sym=1 lines across runs. Prefer substring / per-symbol checks (as multi_tests does).

05

Invariants under concurrency

  1. No cross-shard book touch — enforced by construction (Shard owns its engine).
  2. Joins on shutdown — ThreadGuard; no detach.
  3. No hang — ingress_done + wake_all + matchers_left + EventWake.
  4. Move hand-off — after try_push(std::move(…)), producer does not reuse the object.
  5. Drop accounting — ingress / event / unknown-symbol counters on the pipeline.
06

Determinism limits

Usually stableUsually not
Per-symbol fills given no drops Interleaving of shard lines in the publisher log
Final book under quiescence after join Exact p50/p99 values
Drop counters for intentional unknown symbol Which order dropped under racing full queues

Size fill tests so queues do not drop; use a separate case for counter-only overload if needed.

07

ThreadSanitizer (optional)

Not wired in default CMake. Locally you can rebuild a test target with -fsanitize=thread and run multi_tests / e2e_tests. Useful for accidental shared-book bugs; slows runs.

08

Decision

Decision

Five hand-rolled binaries: LOB goldens, SPSC unit, one-symbol E2E, multi-symbol smoke, latency. Aggregate / substring oracles for concurrent runs. Rejected: requiring bit-stable multi-shard publisher logs as the primary test.
